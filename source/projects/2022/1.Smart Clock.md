## 项目概览

Smart Clock 是一款基于 **Intel Cyclone IV E EP4CE10F17C8 FPGA** 的多功能温湿度电子钟。系统以 50 MHz 时钟为基础，集成日期时间显示、按键设置、音乐闹钟和环境温湿度监测，并扩展了摄像头采集与以太网视频传输功能。

| 项目 | 说明 |
| --- | --- |
| 主控平台 | Intel Cyclone IV E EP4CE10F17C8 |
| 系统时钟 | 50 MHz |
| 开发语言 | Verilog HDL |
| 开发与仿真工具 | Quartus II、ModelSim |
| 主要外设 | DHT11、数码管、74HC595、无源蜂鸣器、OV5640、SDRAM、以太网 PHY |
| 视频分辨率 | 默认 640 × 480 |

**演示视频：**[在 Bilibili 查看 Smart Clock 展示](https://www.bilibili.com/video/BV1nrxszQEKP/)。

**代码仓库：**[Jackma-Q7 / Smart_Clock](https://github.com/Jackma-Q7/Smart_Clock)。

## 主要功能

### 日期、时间与闹钟

- 支持年月日、时分秒显示，默认显示时分秒。
- 通过按键调整当前日期、时间和闹钟时间。
- 到达闹钟时间后输出报警信号，驱动无源蜂鸣器播放音乐。

### 温湿度监测与报警

- 使用 DHT11 采集环境温度和湿度。
- 通过数码管动态显示采集结果。
- 温度达到预设阈值时触发报警信号。

### 显示与按键交互

- 使用 74HC595 将串行控制数据转换为数码管的段选、位选并行信号。
- 在 FPGA 逻辑中对机械按键进行约 20 ms 的消抖处理，输出稳定的按键脉冲。

### 实时视频传输

- 使用 OV5640 采集图像。
- 使用 SDRAM 缓存图像帧数据。
- 通过 UDP 协议，经 RMII 接口和以太网 PHY 将图像数据发送至 PC 上位机。

## 系统组成

### 硬件模块

| 模块 | 作用 |
| --- | --- |
| Intel Cyclone IV E EP4CE10F17C8 | FPGA 主控 |
| DHT11 | 温湿度采集 |
| 74HC595 | 数码管位选、段选串并转换 |
| 无源蜂鸣器 | 闹钟与温度报警提示 |
| OV5640 | 图像采集 |
| SDRAM | 图像帧缓存 |
| 以太网 PHY | UDP/RMII 图像数据发送 |

### 数据流与控制关系

电子钟部分由按键输入控制日期、时间和闹钟设置，显示逻辑将结果送至 74HC595 和数码管；DHT11 采集的温湿度数据用于显示和温度报警判断，报警信号用于驱动蜂鸣器。

视频部分的数据通路为：

```text
OV5640 图像采集 → SDRAM 帧缓存 → 图像打包 → UDP 发送 → RMII / PHY → PC 上位机
```

| 文件 | 职责 |

## 参数配置

`RTL/main.v` 中提供了主要可配置参数：

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| `BOARD_MAC` | FPGA 板卡 MAC 地址 | `48'h12_34_56_78_9A_BC` |
| `BOARD_IP` | FPGA 板卡 IP 地址 | `169.254.1.23` |
| `BOARD_PORT` | FPGA UDP 端口 | `1234` |
| `DES_MAC` | PC 端 MAC 地址 | `48'h00_E0_39_00_20_C9` |
| `DES_IP` | PC 端 IP 地址 | `192.168.0.108` |
| `DES_PORT` | PC 端 UDP 端口 | `1234` |
| `H_PIXEL` / `V_PIXEL` | 图像宽度 / 高度 | `640` / `480` |
| `ALARM_T` | 温度报警阈值，按温度值的 10 倍表示 | `200`，即 20 ℃ |
| `INIT_*` | 初始时间、日期及年份字段 | `12:00:00`、`08/31`、年份字段 `02` |

上述网络地址是工程中的默认配置，使用前需要按实际连接环境调整：

- `BOARD_*` 对应 FPGA 板卡的网络信息，`DES_*` 对应接收端 PC。
- 将 `DES_MAC`、`DES_IP` 设置为实际接收网卡的 MAC 和 IPv4 地址，并确认双方网络可达。
- PC 上位机的接收端口应与 `DES_PORT` 一致。
- 初始年份字段 `02` 的实际含义应结合日期逻辑确认，不直接将其解释为完整年份。

## 构建与下载

根据现有工程说明，原始工程保留了 RTL 源码、Quartus IP 文件和部分编译输出，但未包含完整的 `.qpf/.qsf` 工程文件。重新构建时需要建立工程，并补齐器件、引脚及所需时序约束。

1. 使用 Quartus II 新建工程，选择器件 `EP4CE10F17C8`，顶层实体设置为 `main`。
2. 将 `RTL/` 下所有 Verilog 源文件加入工程。
3. 将 `RTL/ip_core/` 下的 `.qip` IP 文件加入工程。
4. 对照实际硬件和 `DOC/FPGA菁英挑战赛作品报告.md` 设置引脚约束，并检查时钟与时序约束。
5. 根据硬件环境修改 `RTL/main.v` 顶层参数中的网络地址、报警阈值和初始时间。
6. 编译工程并下载生成的 `.sof` 文件到 FPGA。

已有编译结果可参考 `PRJ/output_files/main.sof` 及同目录下的 Quartus 报告文件。使用已有 `.sof` 前，应确认目标板卡、器件和引脚连接与原工程一致。

| 文件 | 覆盖模块 |
| --- | --- |
| `tb_clock_top.v` | 基础时钟、日期切换与闹钟显示 |
| `tb_alarm.v` | 闹钟时间设置 |
| `tb_buzzer.v` | 蜂鸣器音乐输出 |
| `tb_key_filter.v` | 按键消抖 |
