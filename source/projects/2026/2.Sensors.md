## 项目概览

Sensors 围绕多传感器系统的搭建与联调，整理硬件连接、时间同步、驱动配置和标定资料，涉及 **STM32、激光雷达、工业相机和 IMU**。

项目通过 STM32 定时器、UART 授时与 PPS / 触发信号联调，实现雷达与工业相机的同步采集；在 ROS 2 环境下配置传感器驱动，并完成相机内参与雷达—相机外参标定。

**项目仓库：**[Jackma-Q7 / Sensors](https://github.com/Jackma-Q7/Sensors)。

## 技术栈

| 方向 | 技术与工具 |
| --- | --- |
| 嵌入式开发 | C/C++、STM32、TIM 定时器 |
| 硬件接口 | GPIO、UART、TTL 触发、以太网 |
| 时间同步 | PPS 秒脉冲、GPRMC 报文、UTC 时间基准 |
| 驱动与通信 | ROS 2、激光雷达与工业相机驱动 |
| 传感器标定 | Kalibr、Direct Visual-LiDAR Calibration |

## 主要工作

### 硬件连接与接口调试

负责 STM32 同步器、激光雷达及工业相机的硬件连接与接口调试，完成 UART 串口、GPIO、PPS 秒脉冲及以太网通信链路的配置与联调。

### 时间同步与触发联调

调试 STM32 TIM 定时器、GPIO / TTL 触发及 UART 授时链路，结合 PPS 秒脉冲与 GPRMC 报文建立 UTC 时间基准，实现雷达与工业相机同步采集。

### 驱动配置与传感器标定

- 基于 ROS 2 配置激光雷达和工业相机驱动。
- 排查传感器通信与时间戳异常。
- 使用 Kalibr 和 Direct Visual-LiDAR Calibration，完成相机内参与雷达—相机外参标定。
