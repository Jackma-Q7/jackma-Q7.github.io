###  2.3.1 gcc简介  
&emsp;&emsp;gcc是GNUCompilerCollection的简称，是GNU(GNU'sNotUnix)开源项目的编译器套件。gcc的 初衷是为GNU操作系统专门编写的一款编译器，用于编译C代码。现如今已扩展为可以编译C++、 Java、Objective-C等多种编程语言的集合。gcc本身也遵循GPL发行许可证，大名鼎鼎的linux就是基 于gcc搭建的编译系统。gcc官方网站(https://gcc.gnu.org/)

###  2.3.2 安装gcc  
sudo apt-get update 

sudo apt-get install build-essential  

输入以下命令确认版本号：

gcc -v  

 2.3.3 gcc编译  

 gcc命令的建议格式如下：  

 gcc -o output input -option  

 gcc常见命令：  

1. [gcc-E]：预编译 

2. [gcc-S]：生成汇编 

3. [gcc-c]：生成目标文件 

4. [gcc-o]：生成可执行文件 

5. [gcc-I]：添加头文件目录 

6. [gcc-D]：定义宏 

7. [gcc-g]：添加调试信息 

8. [gcc-v]：打印gcc版本信息
