## 项目简介

基于 FishBot 平台开展的移动巡检机器人项目（原工程名 Uptcar），覆盖从 **ESP32 底盘驱动、闭环控制到 ROS 2 通信** 的开发流程，并在 Gazebo 中开展建图、导航与视觉检测实验。

下位机负责电机控制、编码器反馈、IMU 采集和状态管理，通过 micro-ROS 接入上位机；仿真端结合 Cartographer、Nav2 与 YOLO，验证建图、导航和火焰检测流程。

**项目仓库：**[Jackma-Q7 / Fishbot](https://github.com/Jackma-Q7/Fishbot)。

## 主要工作

### 嵌入式驱动与底盘控制

- 使用 ESP32 MCPWM 驱动双轮电机，PCNT 读取编码器，I²C 接入 MPU6050 和 OLED，并集成电池电压检测。
- 实现差速运动学、里程计积分与双轮独立 PID 速度闭环。
- 基于 FreeRTOS 划分控制、通信、传感器和界面任务，控制周期为 10 ms，通过队列与互斥锁协调数据访问。
- 支持 NVS 参数持久化、速度指令超时停转和 Agent 断连停转。

### micro-ROS 通信

- 支持 UART 与 Wi-Fi UDP，通过 micro-ROS Agent 接入 ROS 2。
- 使用 rclc Executor 管理速度订阅、传感器发布和配置服务。
- 通过状态机管理 Agent 连接、断线重连与时间同步。

### 仿真、导航与视觉检测

- 使用 URDF/Xacro 和 Gazebo Classic 构建机器人模型，接入激光雷达、IMU 与 RGB 相机。
- 配置 Cartographer 二维建图，以及 Nav2 的 AMCL 定位、路径规划和跟踪。
- 默认导航控制器为 DWB，另提供 Pure Pursuit 插件与里程计 / IMU EKF 融合实验配置。
- 集成 YOLO 火焰检测，输出检测状态与标注图像。

## 技术栈

| 方向 | 技术与工具 |
| --- | --- |
| 嵌入式开发 | ESP32、C++、PlatformIO、FreeRTOS、PID |
| 通信与集成 | micro-ROS、UART、Wi-Fi UDP、ROS 2 Humble |
| 仿真与可视化 | Ubuntu 22.04、URDF/Xacro、Gazebo Classic 11、RViz2 |
| 建图与导航 | Cartographer、Nav2、AMCL、DWB、Pure Pursuit、EKF |
| 视觉检测 | Ultralytics YOLO、OpenCV、cv_bridge |
