### 2.2.1 vim简介 
&emsp;&emsp;vim是从vi发展出来的一个文本编辑器。具有代码补全、快速跳转、查找等功能，在linux中被广 泛使用。vim官方网站(https://www.vim.org/)  

<img src="/accumulation/1.嵌入式C语言高阶版/graph/2.2.png" width="600" height="400"/>

 「正常模式」： 

这个模式下一般用于阅读、复制粘贴、文本替换、文本查找等功能。  

 「输入模式」： 

这个模式用于文本编辑输入。  

 「命令行模式」： 

这个模式用于文件的保存、退出等功能。  

###  2.2.2 安装vim  
 sudo apt-get install vim  

###  2.2.3 vim增删改查 
通过vim编写一个helloworld代码。 

1、输入以下命令打开一个空的文件，此时默认进入了正常模式  

 vim hello-world.c  

2、按键盘中的「i」进入编辑模式，并输入helloworld的代码  

3、在输入模式下，按键盘中的「Esc」进入正常模式，此时输入「/hello」可进行查找hello字符  

4、在正常模式下，按键盘中的「:」进入命令行模式，输入「wq」，保存并退出。如果不想保存可以 输入「q!」强制退出  

&emsp;&emsp;以上就相当于vim入门，可以完成文本的编辑、查找、保存基础操作。vim是一个工具，大家在学习） 的时候不需要强行记忆命令，要学会在使用中熟练和记忆。下面介绍一个vim学习的神器：vimtutor。  

###  2.2.4 vimtutor 

&emsp;&emsp;vimtutor是vim自带的一个交互式教程程序，通过它你可以轻松掌握vim的基本使用方法和技巧，在 终端中输入：  

 vimtutor zh
