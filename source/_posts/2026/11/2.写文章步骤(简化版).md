## 1. 创建

在下面的文件夹中新建一个 `.md` 文件，例如 `3.STM32学习笔记.md`：

```text
C:\Users\qq7\Desktop\my-blog\source\_posts\2026\11
```

复制模板，修改标题、日期、网址和正文：

```markdown
---
title: STM32 学习笔记
date: 2026-11-17 20:00:00
permalink: 2026/11/17/stm32-notes/
categories:
  - 嵌入式开发
tags:
  - STM32
cover: /images/banner.jpg
---

这里写文章简介。

## 学习内容

这里写正文。
```

每篇文章的 `permalink` 要不同，发布后尽量不改。换月份时，可以新建对应的年月文件夹。

图片放在 `source/images/`，正文引用：

```markdown
![图片说明](/images/图片文件名.jpg)
```

## 2. 预览

打开 PowerShell，执行：

```powershell
cd C:\Users\qq7\Desktop\my-blog
npm run server
```

浏览器打开 <http://localhost:4000/>。保存文章后刷新网页，检查文字、代码和图片。预览结束后，在终端按 `Ctrl + C` 停止服务。

首次运行且尚未安装依赖时，先在项目目录执行一次 `npm ci`。如果端口被占用，运行 `npx hexo server -p 4001`，然后打开 <http://localhost:4001/>。

## 3. 上传

在项目目录执行，确认构建成功后再继续提交和推送：

```powershell
cd C:\Users\qq7\Desktop\my-blog
npm run build
git status
git add .
git diff --cached --stat
git commit -m "新增 STM32 学习笔记"
git push origin main
```

`git add .` 会暂存所有未被忽略的改动，提交前检查状态和暂存摘要；提交说明换成这次实际更新的内容。

推送后，打开[仓库 Actions](https://github.com/Jackma-Q7/Jackma-Q7.github.io/actions)，等待 **Deploy Hexo to GitHub Pages** 部署成功，再访问 <https://Jackma-Q7.github.io/>。

首次发布时，在仓库 **Settings → Pages → Source** 选择 **GitHub Actions**。后续只需重复这三步，网站会自动发布，无需手动上传 `public/` 文件夹。
